# Daniel Alabi | Technical Portfolio

An index of research PDFs, engineering design material, and interactive browser tools.

## Three-step review path

For an engineering or applied-AI hiring manager:

1. **Research and validation:** Read the [UHPC field-test manuscript](Alabi%20et%20al_compressed.pdf) for the sensing method and its comparison with computed tomography (CT) measurements.
2. **System design:** Review the [home-automation proposal](home-automation-system-design.md) for architecture, edge object detection, integration choices, and a staged implementation plan.
3. **Interactive implementation:** Explore [FM.LAB](fm-lab.html) or [LOOM](loom.html), then inspect the HTML/JavaScript alongside the visualization.

## Technical artifacts

| Item | Contents |
| --- | --- |
| [Home-automation system design](home-automation-system-design.md) | Design proposal covering Home Assistant, Frigate, sensors, local control, hardware options, and a staged build plan. |

To run an HTML tool, download the file or clone this repository, then open it in a modern browser. The Fourier series visualizer loads Chart.js from a CDN and needs internet access.
